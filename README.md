# Weather Data Analyzer

## Overview
The **Weather Data Analyzer** is a simple C++ program designed as a semester project to demonstrate fundamental programming concepts. The program allows users to record daily temperatures, calculate averages, and generate weekly temperature reports. It incorporates arrays, 2D arrays, loops, selection statements, and modular functions, providing a practical example of C++ programming concepts.

---

## Features
- Input daily temperatures for a week (up to 7 days).
- Calculate and display:
  - Average temperature
  - Highest temperature
  - Lowest temperature
- Generate a **weekly report** using a 2D array (2 weeks, 7 days each).
- Modular code using functions for input, calculations, and reporting.
- Interactive menu for user-friendly experience.

---

## Programming Concepts Used
1. **User Input and Output**  
   - `cin` and `cout` used for interactive input and output.

2. **Operators**  
   - Arithmetic operators for calculations (sum, average).  
   - Relational operators for finding highest and lowest values.

3. **Selection Statements**  
   - `if-else` statements for comparisons.  
   - `switch-case` used for menu selection.

4. **Loops**  
   - `for` loops for array traversal.  
   - `do-while` loop for menu navigation.

5. **Arrays**  
   - One-dimensional array to store daily temperatures.  

6. **2D Arrays**  
   - Two-dimensional array to store weekly temperatures for multiple weeks.

7. **Functions**  
   - Modular programming using functions:
     - `inputTemperatures()`  
     - `calculateAverage()`  
     - `findHighest()`  
     - `findLowest()`  
     - `weeklyReport()`
